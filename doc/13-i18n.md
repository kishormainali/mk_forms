# 13. Internationalization

Built-in validator messages and widget texts are localized (English and Spanish ship in the box).

## Resolution order

For built-in widgets: `MkLocalizationScope` → `Localizations.of` (the `MkFormLocalizations.delegate`) → `MkFormLocalizations.current`.
`MkFormLocalizations.current` is only a fallback for code with no `BuildContext` (e.g. `MkValidators` running in the bloc layer).

## Setup

```dart
MaterialApp(
  localizationsDelegates: const [
    MkFormLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
  supportedLocales: MkFormLocalizations.supportedLocales, // en, es
  home: const HomeScreen(),
)
```

## Overrides

| Need | Use |
|---|---|
| App-wide default (no context) | `MkFormLocalizations.current = MyMessages();` |
| One subtree | `MkLocalizationScope(messages: SpanishMessages(), child: …)` |
| Live locale switch | `Localizations.override(context: context, locale: l, child: …)` |

## Custom messages and field-aware text

Extend `MkFormMessages` and override `required()`, `email()`, `minLength(n)`, `maxLength(n)`, `min(n)`, `max(n)`, `pattern()`, `match()`. Built-in validators are *field-aware* (“Email is required.”): the label is derived from the controls-map key or an explicit `label:`. Custom classes opt in by overriding the `*Field(String field)` methods (`requiredField`, `emailField`, `minLengthField`, `maxLengthField`, `minField`, `maxField`, `patternField`, `matchField`); otherwise they fall back to the plain methods.

Labels come from (usually English) keys, so for non-English text pass an explicit translated `label:` per field.

## Full example — runtime English ↔ Spanish ↔ custom French

```dart
import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'package:mk_forms/mk_forms.dart';

/// Custom messages with field-aware overrides.
class FrenchMessages extends MkFormMessages {
  @override String required() => 'Ce champ est obligatoire';
  @override String email() => 'Adresse e-mail invalide';
  @override String minLength(int min) => 'Au moins $min caractères';
  @override String maxLength(int max) => 'Au plus $max caractères';
  @override String min(num min) => 'Minimum $min';
  @override String max(num max) => 'Maximum $max';
  @override String pattern() => 'Format invalide';
  @override String match() => 'Les valeurs ne correspondent pas';

  // Field-aware variants (opt in).
  @override String requiredField(String field) => '$field est obligatoire';
  @override String emailField(String field) => '$field : adresse invalide';
}

void main() => runApp(const App());

class App extends StatefulWidget {
  const App({super.key});
  @override
  State<App> createState() => _AppState();
}

class _AppState extends State<App> {
  Locale _locale = const Locale('en');

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      locale: _locale,
      localizationsDelegates: const [
        MkFormLocalizations.delegate,
        GlobalMaterialLocalizations.delegate,
        GlobalWidgetsLocalizations.delegate,
        GlobalCupertinoLocalizations.delegate,
      ],
      supportedLocales: MkFormLocalizations.supportedLocales,
      home: I18nScreen(
        locale: _locale,
        onLocale: (l) => setState(() => _locale = l),
      ),
    );
  }
}

class I18nScreen extends StatefulWidget {
  const I18nScreen({super.key, required this.locale, required this.onLocale});
  final Locale locale;
  final ValueChanged<Locale> onLocale;
  @override
  State<I18nScreen> createState() => _I18nScreenState();
}

class _I18nScreenState extends State<I18nScreen> {
  late final MkSimpleFormBloc _form;
  bool _french = false;

  @override
  void initState() {
    super.initState();
    _form = MkSimpleFormBloc(
      controls: {
        'email': MkFieldBloc<String>(
          label: 'Email',
          validators: [MkValidators.required(), MkValidators.email()],
        ),
        'name': MkFieldBloc<String>(
          label: 'Name',
          validators: [MkValidators.required(), MkValidators.minLength(3)],
        ),
      },
      onSubmit: (v) async => v,
    );
  }

  @override
  void dispose() {
    _form.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    Widget body = MkFormScope.value(
      value: _form,
      child: ListView(padding: const EdgeInsets.all(16), children: [
        SegmentedButton<Locale>(
          segments: const [
            ButtonSegment(value: Locale('en'), label: Text('EN')),
            ButtonSegment(value: Locale('es'), label: Text('ES')),
          ],
          selected: {widget.locale},
          onSelectionChanged: (s) => widget.onLocale(s.first),
        ),
        SwitchListTile(
          title: const Text('Use custom French messages (scoped)'),
          value: _french,
          onChanged: (v) => setState(() => _french = v),
        ),
        const MkEmailField(name: 'email'),
        const SizedBox(height: 12),
        const MkTextField(name: 'name', decoration: InputDecoration(labelText: 'Name')),
        const SizedBox(height: 16),
        FilledButton(onPressed: _form.submit, child: const Text('Submit')),
      ]),
    );

    // Scoped override affects only this subtree.
    if (_french) {
      body = MkLocalizationScope(messages: FrenchMessages(), child: body);
    }
    return Scaffold(appBar: AppBar(title: const Text('i18n')), body: body);
  }
}
```

Press Submit with empty fields, then flip the locale — visible errors update immediately.
